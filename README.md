# Evolution Simulator
Program that simulates AI neural network training in a visual way. Made (and hosted) with OpenProcessing. All AI and UI libraries and architectures are custom made
## How to Run
Go to this link https://openprocessing.org/@u488274/2469924 and:
* The simulation will open up on visiting the site. Close the intro text and press start in the top left
* Press the “Code” button at the top of the screen to view the source code (or alternatively view it here)
